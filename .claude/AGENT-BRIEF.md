# Преамбула агента

Это стартовая страница для субагента: **ядро, обязательное всем**, и **маршрут к правилам своей
зоны**. Ядро можно прочитать целиком за минуту. Правила своей и смежных зон читаются **полностью** —
не в пересказе: выжимка правила это не правило, а мнение о нём.

`CLAUDE.md` целиком читать не обязательно. Обязательно — раздел «Три неприкосновенных инварианта» и
то, что относится к твоей зоне по таблице ниже.

---

## Ядро (всем, без исключений)

**1. Три инварианта.** Нарушение любого — блокирующий дефект, а не замечание. Все три объединяет то,
что ошибка **не проявляется функционально**: приложение работает, тесты зелёные, данные утекают.

- нет таблицы арендатора без `organizationId`, `ENABLE`+`FORCE` RLS, политики с `USING` **и**
  `WITH CHECK`, и isolation-теста **с положительным контролем**;
- каждый endpoint объявляет право из закрытого каталога и проверяет его **в use-case**; чужая
  организация — **404, а не 403**;
- ничего расшифрованного из vault не покидает браузер.

Полные формулировки — `CLAUDE.md`, раздел «🔴 Три неприкосновенных инварианта».

**2. Источники истины и их порядок.** `docs/` → `epics/` → код. Если `docs/` неверен — сперва
правится `docs/`. Расхождение между слоями **эскалируется, а не решается молча**.

**3. Доказательство красного.** Тест, который не видели падающим, не написан. Внеси дефект, который
тест обязан поймать, приведи **точное сообщение падения**, откати. Случай, для которого дефект
подобрать не удалось, скорее всего ничего не утверждает — скажи об этом, а не оставляй как есть.

Две ловушки, на которых уже попадались:

- **ассерт по подстроке** находит искомое в человекочитаемом сообщении рядом с проверяемым — и
  остаётся зелёным под дефектом;
- **фикстура вместо цели**: правило срабатывает на искусственном файле, но не наведено на
  отгружаемый код. Проверяй, что цель существует.

**4. Параллельная работа.** В дереве одновременно работают другие агенты.

- пиши **только** в свою зону; чужие незакоммиченные правки не откатывай и не «прибирай»;
- диагностика — точечно, с `--coverage.enabled=false`;
- полный прогон пакета **с покрытием — один раз в конце**: два таких прогона по одному пакету
  уничтожают друг друга через общий `coverage/.tmp`;
- красный тест в чужой зоне может быть чужой мутацией в полёте — не чини, сообщи;
- вердикт выносится только на тихом дереве. Не можешь прогнать — так и скажи.

**5. Честность отчёта.** «Написано, но не запущено» — нормальный результат. «Работает» без прогона —
нет. Команда, которую ты **не** выполнил, называется явно.

**6. Не коммить.** Коммит собирает оркестратор.

**7. Зависание.** Команда, не ответившая за ~2 минуты без вывода, бросается; в отчёте — что успел.

## Маршрут: что читать полностью

Найди свою строку. Читаешь **свою зону и смежные**; чужие — не нужны.

| Зона правки | Читать полностью |
|---|---|
| `packages/server/src/**` | `hexagonal-backend`, `tenancy-rls`, `permissions`, `security`, `zod-validation`, `observability` |
| `prisma/schema.prisma`, `prisma/migrations/**` | `db-migrations`, `tenancy-rls`, `self-host-packaging` |
| `docs/api/openapi.yaml`, контроллеры, коды ошибок | `api-contract`, `zod-validation`, `errors-and-toasts` |
| `packages/client/src/**` | `frontend-fsd`, `design-system`, `tanstack-query`, `errors-and-toasts`, `lists-and-filters`, `i18n`, `a11y` |
| любые тесты | `testing` + правила зоны кода, который тестируешь |
| `packages/e2e/**` | `testing`, `a11y` |
| vault, крипто, secure links | `e2ee-crypto` + `security` (режим «сомнение = FAIL») |
| побочные эффекты вне транзакции | `outbox` |
| сокеты, presence | `realtime` |
| индексация, поиск | `search-index` |
| файлы, presigned URL | `file-uploads` |
| `epics/**`, `docs/product/**` | `epic-driven-development` |
| зависимости | `dependencies` |
| CI, compose, env, профили | `self-host-packaging`, `ci-before-push` |

Всегда, независимо от зоны: `naming-and-structure`, `commit-hygiene`, `tdd-and-commit-gate`.

Правила лежат в `rules/<имя>.mdc`. Если твоя правка задевает зону, которой нет в таблице, — прочитай
`CLAUDE.md`, таблицу «Правила», и назови в отчёте, чего не хватило здесь.
