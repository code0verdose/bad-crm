# Лендинг, который не является продуктом

Задача: собрать маркетинговую страницу Bad CRM так, будто продукт готов — со скролл-завязанными
переходами, без Mantine, с компонентами React Bits. Отдельно от приложения.

## Простым языком

1. **Завёл отдельный пакет `packages/landing`.** Лендинг живёт рядом с приложением, но не трогает
   его: ничего не импортирует, не тянет Mantine, собирается в статику своей командой. Это нужно,
   чтобы визуальные эксперименты на витрине не могли сломать продукт и не раздували его бандл.
2. **Завёл эпик и историю (EPIC-047).** В проекте правило «нет кода без активного эпика», а
   лендинга не было ни в дорожной карте, ни среди 46 эпиков — без этого гейт справедливо упёрся бы.
3. **Дал лендингу собственный язык оформления.** Свои переменные `--bcl-*` (цвета, типографика,
   отступы, тени, длительности), тёмная схема по умолчанию и светлая по переключателю. Токены
   приложения (`--bc-*`) не трогал: они измерены под плотные рабочие экраны, у витрины другие задачи.
4. **Научил проектный линтер стилей понимать этот второй язык.** Запрет «никаких литеральных
   значений» остался в силе, но для лендинга он теперь проверяет `--bcl-*`, а брейкпоинты требует в
   `em`, а не в пикселях — иначе размер шрифта читателя игнорируется.
5. **Сделал двенадцать секций, каждая со своим типом движения:** первый экран «складывается» под
   следующий; скриншот приложения выпрямляется из наклона по мере прокрутки; лента заменяемых
   сервисов ускоряется от скорости скролла и вычёркивает названия по очереди; список доменов идёт
   мимо закреплённого заголовка; цепочка «созвон → инвойс» едет вбок, пока секция закреплена;
   четыре карточки-инварианта наезжают друг на друга; демонстрация шифрования переписывает «то, что
   видит сервер» на каждый введённый символ; карточки метрик подсвечиваются под курсором; доска
   сама двигает карточки между колонками.
6. **Перенёс пять компонентов React Bits в репозиторий** (Aurora, CountUp, ScrollVelocity,
   SpotlightCard, Magnet) — с указанием источника и лицензии рядом с каждым. Шестой, SplitText, не
   переносил: он построен на GSAP, а лицензия GSAP не подходит проекту на AGPL — эффект переписан на
   `motion` в десяток строк.
7. **Сделал две равноправные языковые версии.** Русский словарь типизирован по английскому: забытый
   ключ — ошибка компиляции, а не пустой заголовок на странице.
8. **Выключил всё движение для тех, кто его не переносит.** При системной настройке «уменьшить
   движение» плавный скролл не запускается, шейдер не монтируется вовсе, а скролл-трансформы
   застывают в том состоянии, в котором секция читается.

## Технически

1. `packages/landing/package.json` — новый воркспейс `@bad-crm/landing`, лист графа зависимостей.
   Vite 8 + React 19.2.8 (те же пины, что у клиента), `motion@12`, `lenis@1.3`, `ogl@1.0` (MIT),
   `clsx`. Бюджет `size-limit` — 180 kB на первичный чанк; фактически 108.6 kB brotli, шейдер уехал
   в отдельный чанк через `React.lazy`.
2. `eslint.config.js` — блок `packages/landing/**`: `LANDING_IS_LEAF` (запрет импорта любого
   `@bad-crm/*`), запрет `fetch`/`XMLHttpRequest` (страница статическая), свой `import/order` с
   path-group для `@/**` — без него неразрешаемый алиас ранжируется последним и линтер требует
   ставить CSS-модуль выше компонента. `react/forbid-*-props` для `style` намеренно не включён:
   `style` — это API `motion`, через него подписываются `MotionValue`.
3. `stylelint.config.js` — `TOKEN_DECLARATION_FILES` вырос с двух путей до четырёх, плюс override
   `packages/landing/src/**/*.css`: `custom-property-pattern: ^bcl-…`,
   `media-feature-name-value-allowed-list: null` (нет `postcss-simple-vars`), взамен
   `media-feature-name-unit-allowed-list` с единственной допустимой единицей `em`.
   `test/lint/stylelint-rules.test.ts` синхронно обновлён: список исключений и отдельный пробник
   `--bcl-probe`, иначе кейс падал бы на `custom-property-pattern`, а не на том, что проверяет.
4. Архитектура пакета — `app/` (провайдеры, токены, словари), `sections/<name>/<name>.component.tsx`,
   `widgets/`, `shared/{lib,ui}`; имена файлов kebab-case + role-suffix из закрытого словаря
   (`.component`, `.widget`, `.hook`, `.constant`, `.util`, `.provider`, `.context`, `.types`).
   Суффикса `.section` в словаре нет — секции названы `.component.tsx`, чтобы не расширять правило
   ради одного пакета.
5. `shared/lib/use-scene-progress.hook.ts` — единственная точка входа в scroll-таймлайны:
   `useScroll` + `useSpring` (`SCROLL_SPRING`), параметр `raw` для приклеенных к колесу сцен
   (горизонтальный пин) и `staticProgress` — прогресс, на котором сцена замирает при
   `prefers-reduced-motion` (0 для героя, 1 для витрины).
6. `shared/lib/use-reduced-motion.hook.ts` и `use-media-query.hook.ts` — `useSyncExternalStore` над
   `matchMedia`, а не `useEffect` + `useState`: первый же рендер знает ответ.
7. Порты React Bits — `shared/ui/bits/<name>/` c `SOURCE.md` (ссылка на оригинал, лицензия MIT,
   список изменений) и атрибуцией в корневом `NOTICE`. Существенные правки: в `ScrollVelocity`
   верхний компонент объявлял вложенный компонент прямо в теле, из-за чего лента перемонтировалась
   на каждый рендер — портирован только ряд, ширина копии измеряется `ResizeObserver`; в `Magnet`
   смещение переведено со state на `MotionValue` (ноль ре-рендеров); в `SpotlightCard` координаты
   в процентах и цвет из токена; в `CountUp` выкинут разбор дробной части и локаль стала пропом.
8. `app/i18n/` — `dictionary-en.constant.ts` как источник, `Copy = typeof EN_COPY`,
   `dictionary-ru.constant.ts` аннотирован этим типом. `detect-locale.util.ts` — чистая функция
   «сохранённое → `navigator.languages` → en» со сравнением по первому сабтегу; тесты на порядок.
   `test/i18n/dictionary-parity.test.ts` ловит то, что тип не видит: массив другой длины и пустую
   строку (с явным списком легальных пустых — пустая строка терминала и единица измерения метрики).
9. `index.html` содержит инлайн-бутстрап схемы и языка до первой отрисовки — дублирование
   `resolve-scheme.util.ts` осознанное: модуль не может выполниться раньше бандла, а альтернатива —
   белая вспышка на каждой загрузке.
10. Три дефекта, найденные на живой странице, а не в голове:
    - `background-clip: text` на строке заголовка клипался в ничто, потому что слова внутри —
      анимированные `inline-block` со своим `filter`; строка рендерилась невидимой. Заменено на
      сплошной цвет, причина записана в CSS.
    - Пробелы между словами были заданы `margin`, и `textContent` заголовка выглядел как
      `Однорабочееместо.` — сломано копирование, скринридер и индексация. Пробелы стали настоящими
      текстовыми узлами (`word-reveal.component.tsx`).
    - `useId` в поле демонстрации E2EE: React 19 генерирует идентификаторы с `«»`, и поиск по
      подписи в тестовой библиотеке их не находит. Заменено на литеральный id.
11. Тесты: `test/i18n/*` (паритет словарей, детект локали), `test/sections/cipher-noise.test.ts`
    (лавинность, длина конверта, стабильность, счёт по кодовым точкам), `test/app/page.test.tsx`
    (рендер всей страницы, ровно один `h1`, переключение языка с проверкой `<html lang>`, ввод в
    поле E2EE не появляется на странице). Порог покрытия — 80/70 по `shared/lib` и `app/i18n`;
    хореография секций проверяется скриншотом, а не процентом.

## Что осталось за кадром

Скриншотами проверен только первый экран: панель предпросмотра в этой среде не перерисовывает
захват после прокрутки — DOM и хит-тестинг на прокрученных позициях корректны, но кадр приходит
чёрным. Остальные секции проверены структурно (`get_page_text` по всей странице) и тестами.
Смотреть глазами — `pnpm --filter @bad-crm/landing dev`, <http://localhost:4321>.

## Ревизия по замечаниям (тот же день)

Двенадцать правок после первого просмотра. Существенное — не косметика:

1. **Скролл-сцена витрины считалась в колонке.** Центрированная flex-колонка раскладывает сверху
   вниз, а кадр по мере разворота растёт — прибавка съедалась сверху (заголовок обрезался) и
   оставалась пустотой снизу. Стало три строки грида: заголовок, сцена, подпись; кадр растёт вокруг
   собственного центра внутри строки, высота которой решена до анимации.
2. **Горизонтальная сцена ехала в процентах.** Процент от ширины трека не имеет отношения к
   контейнеру: последняя карточка улетала за левый край. Теперь дистанция измеряется —
   `track.scrollWidth − viewport.clientWidth`, — и трек останавливается ровно тогда, когда правый
   край последней карточки совпал с правым краем контейнера.
3. **`useTransform` запоминает функцию с первого рендера** — дважды подряд одна и та же ловушка:
   сначала `distance` из состояния (0 на монтировании), потом `reduced` из хука. Оба раза трек молча
   не двигался. Правило по итогу: в трансформер входят **только** motion-значения, а
   `prefers-reduced-motion` обрабатывается там, где ему место — в `useSceneProgress`.
4. **Подсветка в списке доменов дёргалась,** потому что «вошло во вьюпорт» и «читают именно это» —
   разные вопросы, а порог был один. Стало два наблюдателя: раскрытие по четверти карточки, активная
   строка — только пока карточка пересекает узкую полосу через центр экрана.
5. **Окна теперь настоящие macOS-окна:** `window-chrome.component.tsx` — три кнопки в порядке Apple,
   с внутренним кольцом и верхним бликом; один компонент на все три окна страницы.
6. Убраны eyebrow-подписи у всех секций и магнитные кнопки; шапка прячется при скролле вниз и
   возвращается при скролле вверх с порогом 12 px (без порога тачпад заставляет её мигать); полосы
   у ленты заменены на маску; названия сервисов и технологий получили рисованные марки
   (`brand-mark.component.tsx` — своя линейная графика, не логотипы вендоров: логотип это товарный
   знак, а перечёркивать чужой знак — отдельный разговор).

## Применённые технологии

- [[React]] 19 — страница целиком, без единого класса.
- [[Vite]] — сборка и dev-сервер пакета.
- [[Motion]] — `useScroll`/`useTransform`/`useSpring`/`useInView`/shared layout: весь скролл-слой.
- [[Lenis]] — плавный скролл, отключаемый по `prefers-reduced-motion`.
- [[OGL]] — WebGL-фон Aurora, догружается динамически и только на широких экранах.
- [[CSS Modules]] — стили рядом с компонентом, поверх собственных токенов.
- [[React Bits]] — источник пяти портированных эффектов (MIT).
- [[TypeScript]] — словарь RU выводится из EN, расхождение ключей ломает сборку.
