# Сохранённая сессия — одноразовая

Закрывает EPIC-010: джоба e2e в CI, и три вещи, которые нашлись только там.

## Простым языком

1. Харнесс работал локально: пятнадцать сценариев зелёные. В CI он упал — и упал ровно на том, что
   локально проверить было нельзя.
2. **Первая находка — сохранённая сессия неразделяема.** Playwright умеет сохранять состояние входа
   в файл и переиспользовать его во всех сценариях. Это стандартный приём, и здесь он работает
   **один раз**: клиент при загрузке обменивает refresh-cookie, а ротация с обнаружением повторного
   использования означает, что вторая попытка предъявить ту же cookie выглядит как кража токена — и
   семейство отзывается. В CI это видно буквально: первая попытка дошла до оболочки, повтор ушёл на
   `/login`.
   Правильный вывод не «выключить обнаружение», а «сессия чеканится на тест». Стоит это десятки
   миллисекунд против секунд, которые стоит форма, и ни один сценарий по-прежнему не зависит от
   экрана входа, кроме того, который его и проверяет.
3. **Вторая — конфигурация install-руководства проверяется только там, где её исполняют.**
   `cp .env.example .env` не даёт рабочей установки: шаблон содержит `CHANGE_ME`, и схема отвергает
   ключ шифрования, который не 32 байта. Джоба теперь заполняет плейсхолдеры **теми же командами**,
   что печатает раннбук, и падает, если после этого хоть одно присваивание осталось с плейсхолдером.
4. **Третья — плейсхолдеры связаны между собой.** Пароль `app_user` живёт ещё и внутри
   `DATABASE_URL`, креды MinIO — ещё и в `S3_ACCESS_KEY`/`S3_SECRET_KEY`. Замена построчно оставляет
   URL, указывающий на пароль, которого никто не задавал. Замена **по значению** — каждая строка
   плейсхолдера везде, где встречается, — сохраняет связь по построению.

## Технически

1. `fixtures/session.fixture.ts` — фикстура `ownerPage`: логин по API на каждый тест, проверка
   origin тем же обновлением, что делает браузер, состояние — с уже ротированной (свежей) cookie.
2. `.github/workflows/ci.yml` → джоба `end-to-end`: сервисы профилем `minimal`, роли → миграции →
   гранты → сид, браузер, сборка, запуск сервера с `--env-file-if-exists` (как контейнер читает
   окружение; `. ./.env` в shell испортил бы значения с хвостовыми комментариями), прогон,
   сбор логов, скраб, выгрузка.
3. Контракт джобы закрыт `test/ci/workflow.test.ts`: существование и таймаут, сид, установка
   браузера, асимметрия артефактов, срок хранения, скраб **до** выгрузки, логи контейнеров при
   падении. Написан красным.
4. `APP_URL` в шаблоне — адрес API (контейнер отдаёт собранный клиент оттуда же). Джоба отдаёт
   клиент preview-сервером на 5173 и поэтому сообщает установке, где та живёт. Иначе — валидная
   сессия, которую приложение отказывается возобновить.

## Скраб артефактов: где проходит граница

Требование звучало как «в артефактах нет секретов». Реальность сложнее, и разбор стоило записать:

- **файл сессии и `.env`** — чистые учётные данные без доказательной ценности: удаляются;
- **trace, в котором есть cookie**, — это само доказательство. Playwright пишет в trace ответы,
  которые видел, и один из них — вход, выдавший cookie; **любой** trace аутентифицированного
  сценария её содержит. Переписывать его скриптом нельзя: отредактированный trace — это trace,
  которому нельзя верить.

Поэтому trace только называется, а публикация разрешена явным `--ephemeral`, и он означает ровно
одно утверждение: инсталляция создана и уничтожена внутри этого прогона. Умолчание «эфемерно»
сделало бы проверку тихой там, где она нужна; умолчание «фатально» роняло бы каждую выгрузку из-за
cookie, истёкшей вместе с контейнером.

## Что из этого правило, а не случай

- **Приём из документации инструмента может противоречить свойству продукта.** `storageState` —
  правильный приём; ротация с обнаружением повторного использования делает его неприменимым в общем
  виде. Побеждает свойство продукта, а не приём.
- **Документированную команду установки проверяет только тот, кто её исполняет.** CI — первое место,
  где `.env.example` превращается в работающую конфигурацию; до этого он был текстом.
- **Связанные значения заменяются по значению, а не по строке.**
- **Граница «секрет или доказательство» проходит по тому, можно ли это переписать.** Что можно
  удалить без потери смысла — удаляем; что нельзя — называем и решаем явно.
