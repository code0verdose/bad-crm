# EPIC-007 — Дизайн-система

## Зачем (ценность)

Продукт заменяет шесть инструментов и потому будет содержать десятки экранов, сделанных в разное
время. Без общего набора токенов, состояний и правил каждый новый экран будет выглядеть и вести
себя по-своему: где-то спиннер, где-то скелетон, где-то тост на ошибку загрузки, где-то пустой
экран. Эпик фиксирует сужение Mantine до проектного подмножества, даёт единые компоненты состояний
и уведомлений, закладывает a11y-базис и автоматический аудит — так, чтобы соответствие WCAG 2.1 AA
не пришлось ретрофитить перед релизом.

## Scope

### В скоупе

- Токены темы: палитра, spacing, radius, типографика, тени, плотность, motion; светлая и тёмная темы через `light-dark()`.
- Ядро `shared/ui`: `DataState`, набор скелетонов, `EmptyState`, `ErrorState`, `PageHeader`.
- Обёртка тостера над `@mantine/notifications` со стабильными идентификаторами и дедупликацией.
- Layout-примитивы `Section`, `Toolbar`, `SplitPane` и адаптивное поведение.
- A11y-базис: видимый фокус, клавиатурная навигация, skip-link, live-region; axe в CI.
- Мастерская компонентов (Storybook/Ladle) для `shared/ui` с псевдолокалью.

### Вне скоупа

- Доменные компоненты (карточка задачи, строка таймшита) — соответствующие продуктовые эпики; в `shared/ui` они не попадают.
- Локализация строк — [EPIC-008](../epic-008-i18n-en-ru/epic.md) (здесь компоненты принимают ключи, а не готовые строки).
- Графики — [ADR-0017](../../docs/architecture/adr/0017-charts-mantine-charts.md) и [EPIC-031](../epic-031-dashboards/epic.md).
- Таблицы на TanStack Table — вводятся первым списочным доменом (M2), здесь только `PaginationBar` и `FilterBar` как оболочки.

## Acceptance (эпик выполнен, когда)

- [ ] Все цвета, отступы, радиусы и размеры шрифта в CSS-модулях берутся из токенов; литеральные значения падают на линте стилей.
- [ ] Светлая и тёмная темы дают контраст ≥ 4.5:1 для основного текста и ≥ 3:1 для крупного — проверено автоматическим тестом по парам токенов.
- [ ] Любой экран с данными использует `DataState`: состояния загрузки (скелетон), ошибки (с повтором), пустоты (с объяснением следующего шага) и контента реализованы единообразно.
- [ ] Ошибка загрузки списка показывается инлайн, а не тостом; ошибка действия — тостом; за одно действие возникает ровно один сигнал.
- [ ] Все интерактивные элементы достижимы с клавиатуры, имеют видимый фокус и корректный порядок обхода; в модалках работает ловушка фокуса.
- [ ] Автоматический аудит axe на экранах входа и оболочки не находит нарушений уровня A и AA и запускается в CI.
- [ ] Анимации уважают `prefers-reduced-motion`.
- [ ] Компоненты `shared/ui` не знают о доменах и не ходят в сеть — проверяется архитектурным тестом.

## Зависимости / риски

- Зависит от: [EPIC-004](../epic-004-client-shell-fsd/epic.md) (тема Mantine, CSS Modules, оболочка).
- Блокирует: все продуктовые UI-эпики (M2+) и [EPIC-010](../epic-010-e2e-harness/epic.md) в части a11y-аудита.
- Риски: разрастание `shared/ui` доменными компонентами — митигируется правилом «когда заводить свой компонент» и архитектурным тестом; расхождение дизайна и кода — митигируется мастерской компонентов; переполнение вёрстки при длинных русских строках — митигируется псевдолокалью в мастерской (связка с [EPIC-008](../epic-008-i18n-en-ru/epic.md)).
