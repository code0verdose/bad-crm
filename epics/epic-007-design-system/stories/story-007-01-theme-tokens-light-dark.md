# STORY-007-01 — Токены темы и светлая/тёмная схемы

**Как** разработчик Bad CRM **я хочу** зафиксированный набор токенов цвета, отступов, радиусов и
типографики **чтобы** новый экран автоматически выглядел как остальные, а тёмная тема не
требовала отдельной вёрстки.

## Acceptance (Given/When/Then)

- **Given** тема проекта **When** смотрю доступные роли цвета **Then** объявлены brand, neutral, success, warning, danger, info и accent (маркер AI); произвольные цвета вне палитры в коде отсутствуют.
- **Given** семантические алиасы (`--bc-surface`, `--bc-border`, `--bc-text`, `--bc-text-muted`, `--bc-danger-surface`) **When** переключаю тему **Then** значения меняются через `light-dark()` без второго набора классов.
- **Given** пары «текст на поверхности», «текст на кнопке brand», «ссылка на поверхности», «текст на danger-поверхности» **When** запускается тест контраста **Then** в обеих темах отношение ≥ 4.5:1 (≥ 3:1 для крупного текста); нарушение валит сборку.
- **Given** CSS-модуль с `padding: 13px` **When** запускается stylelint **Then** он падает: используется шкала (`var(--mantine-spacing-*)`) или `calc()` от неё.
- **Given** экран **When** смотрю его радиусы **Then** контролы — `sm`, карточки — `md`, оверлеи — `lg`; тест-правило ограничивает число разных радиусов на экране двумя.
- **Given** страница **When** проверяю заголовки **Then** ровно один `h1` (в `PageHeader`), иерархия без пропусков уровней — проверяется тестом разметки.
- **Given** `prefers-reduced-motion: reduce` **When** воспроизводится любой переход **Then** длительность равна нулю; токены `--bc-motion-fast/base` не применяются.
- **Given** режим плотности `compact` **When** он включён **Then** высота строк таблиц меняется через `--bc-row-height`, а не через переопределение отступов в компонентах.
