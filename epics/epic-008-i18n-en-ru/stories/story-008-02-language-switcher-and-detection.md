# STORY-008-02 — Переключатель языка, сохранение и определение локали

**Как** разработчик (пользователь продукта) **я хочу** выбрать язык интерфейса один раз **чтобы**
он применялся сразу, сохранялся между сессиями и переносился на другие устройства.

## Acceptance (Given/When/Then)

- **Given** первый визит без сохранённого выбора **When** браузер сообщает `Accept-Language: ru-RU` **Then** интерфейс открывается на русском; при неизвестном языке — на английском.
- **Given** порядок определения локали **When** он применяется **Then** используется цепочка: профиль пользователя → `localStorage` → `navigator.language` → `en`; каждый шаг покрыт тестом.
- **Given** переключатель языка в меню аватара или на `/settings/appearance` **When** я меняю язык **Then** интерфейс переключается мгновенно без перезагрузки, `<html lang>` обновляется, выбор сохраняется в `localStorage`.
- **Given** аутентифицированный пользователь **When** он меняет язык **Then** выбор сохраняется в профиле (после [EPIC-012](../../epic-012-employee-management/epic.md)); до тех пор — только локально, и это явно отражено в интерфейсе.
- **Given** публичный экран `/login` **When** пользователь не аутентифицирован **Then** переключатель языка доступен и работает — профиля ещё нет.
- **Given** сохранённая локаль **When** страница перезагружается **Then** правильный язык применяется до завершения загрузки сессии (без «мигания» английского).
- **Given** серверные письма (например, сброс пароля) **When** они отправляются **Then** язык письма берётся из профиля пользователя, а при его отсутствии — из языка организации, затем `en`.
