# STORY-017-06 — Quickstart, runbook и smoke-тест чистой установки

**Как** владелец инсталляции (P1) **я хочу** пошаговую инструкцию, по которой система поднимается за
десять минут, и уверенность, что этот путь проверяется автоматически, **чтобы** «у меня не
заработало» было багом с воспроизведением, а не вечным свойством self-host-продукта.

## Acceptance (Given/When/Then)

1. **Quickstart в README.**
   Given `README.md`;
   When владелец его открывает;
   Then первые экранные страницы — путь из 5 шагов: клонировать → `./scripts/bootstrap-secrets.sh` →
   заполнить домен в `.env` → `docker compose -f docker-compose.prod.yml --profile full up -d` →
   открыть `APP_URL` и войти; указаны минимальные требования по профилям и ссылка на
   `docs/runbooks/install.md`.

2. **Runbook установки покрывает чек-лист безопасности.**
   Given `docs/runbooks/install.md`;
   When он читается;
   Then он содержит **все 13 пунктов** чек-листа безопасной установки из `threat-model.md`
   (секреты, TLS, закрытые порты, приватный бакет, роль БД, хранение `APP_ENCRYPTION_KEY`,
   обязательная 2FA, шифрованные бэкапы, `SIGNUP_MODE`, SMTP, решение по AI, доступ к `/metrics`,
   подписка на security-релизы) с пояснением, чем грозит пропуск каждого.

3. **Диагностика типовых проблем.**
   Given раздел «Troubleshooting»;
   When владелец сталкивается с ошибкой;
   Then описаны: сообщения preflight и их исправление, «контейнер перезапускается» (миграции),
   «нет сертификата» (порты 80/443, DNS), «файлы не загружаются» (бакет/креды), «поиск не работает»
   (профиль `minimal`), «письма не приходят» (SMTP), с командами проверки.

4. **Smoke-тест «чистая установка» в CI.**
   Given workflow `install-smoke.yml`;
   When изменяются `docker-compose.prod.yml`, `Dockerfile`, entrypoint, `.env.example`, скрипты
   bootstrap или preflight;
   Then CI на чистом раннере выполняет весь путь из quickstart и проверяет: контейнеры здоровы,
   `/healthz` и `/readyz` отвечают, миграции применены, сид справочников выполнен, вход владельца
   работает, создание проекта и загрузка файла проходят end-to-end.

5. **Замер времени как контрактное требование.**
   Given smoke-прогон;
   When он завершается;
   Then измеряется время от старта до успешного входа; превышение порога (10 минут медианы на
   протоколе проверки, с поправкой на прогрев кеша CI) помечает прогон красным — NFR-3 проверяется,
   а не декларируется.

6. **Прогон без исходящего интернета.**
   Given сетевая песочница без доступа наружу (после подтягивания образов);
   When выполняется smoke-тест;
   Then он проходит полностью: ни один основной сценарий не требует внешнего сервиса; отсутствие
   SMTP, AI и GitHub не ломает ничего (NFR-9).

7. **Профиль `minimal` проверяется отдельно.**
   Given матрица прогонов;
   When CI выполняет smoke;
   Then он гоняется для обоих профилей (`full` и `minimal`); в `minimal` дополнительно проверяется,
   что поиск деградирует, а не падает.

8. **Негативные сценарии в smoke.**
   Given намеренно испорченная конфигурация;
   When выполняется прогон;
   Then проверяется, что: с примерным `JWT_SECRET` контейнер **не** стартует; с `http://APP_URL`
   вне разработки — не стартует; при публичном бакете — не стартует; анонимный `GET` в MinIO
   даёт 403; инфраструктурные порты не слушают на внешнем интерфейсе.

9. **Артефакты прогона.**
   Given упавший smoke;
   When разбирается причина;
   Then в артефактах CI лежат логи всех контейнеров, вывод preflight и отчёт по времени шагов —
   без секретов (маскирование применяется и к артефактам).

10. **Документация обновляется вместе с поставкой.**
    Given изменение в compose, env или entrypoint;
    When открывается PR;
    Then шаблон PR требует отметить, обновлены ли quickstart и runbook; тест
    `docs-in-sync.spec.ts` сверяет список переменных в `.env.example` с таблицей в
    `docs/runbooks/install.md` и падает при расхождении.

11. **Ограничения альфы честно заявлены.**
    Given раздел «Что альфа не умеет»;
    When владелец его читает;
    Then явно перечислено: нет проверенной процедуры обновления между релизами (это M9,
    [EPIC-046](../../epic-046-self-host-release-1-0/epic.md)), нет антивируса (принятый риск
    `T-FILE-05`), нет бэкапов из коробки (только скрипт и инструкция), доменов ТЗ реализовано
    ограниченное число.
