# STORY-048-03 — Персональные токены и stdio-мост

**Как** разработчик **я хочу** подключить локального агента одной строкой в его конфигурации
**чтобы** пользоваться Bad CRM из Claude Desktop или Cursor, не поднимая ничего у себя.

## Acceptance (Given/When/Then)

- **Given** страница «Мои токены» **When** пользователь создаёт токен **Then** значение показывается
  **один раз**, в БД хранится только SHA-256, в списке видны имя, последние 4 символа, область
  действия, срок и когда токен использовался в последний раз.
- **Given** токен **When** он создаётся **Then** обязательны срок действия и **область — закрытый
  список инструментов**; «все инструменты» — это явный выбор, а не значение по умолчанию.
- **Given** токен с областью `tasks.*` **When** агент зовёт `time.log` **Then** отказ, и инструмента
  нет в `tools/list` — область сужает набор, но никогда не расширяет права.
- **Given** отозванный токен **When** им делают следующий вызов **Then** отказ немедленно, без
  ожидания истечения и без кеша решения.
- **Given** `@bad-crm/mcp-stdio` **When** его исходники проверяются **Then** он не содержит ни одного
  инструмента, не обращается к БД и не имеет зависимости на `@bad-crm/server` — он перекладывает
  кадры JSON-RPC в `POST /mcp` и обратно.
- **Given** мост **When** сервер недоступен или токен отозван **Then** клиент получает внятную
  ошибку протокола, а не молчание и не зависший процесс.
- **Given** токен в конфигурации агента **When** он попадает в вывод моста или в его логи **Then**
  этого не происходит: тест на редакцию, как для логов сервера.

## Задачи

- [ ] Тесты первыми: только хеш в БД; область сужает `tools/list`; отзыв действует немедленно;
      мост не имеет зависимостей на исходники продукта (архитектурный тест графа пакетов).
- [ ] Сущность `ApiToken` + миграция с RLS по канону (`organizationId`, `USING`+`WITH CHECK`,
      `FORCE`, isolation-тест с положительным контролем).
- [ ] Use-case'ы: создать, показать список, отозвать (self-service, `ownershipCheckedIn`).
- [ ] Экран «Мои токены» в клиенте, EN + RU, предупреждение «значение больше не будет показано».
- [ ] Пакет `packages/mcp-stdio`: `bin`, чтение `BAD_CRM_URL` и `BAD_CRM_TOKEN` из окружения,
      прокидывание кадров, коды выхода.
- [ ] Runbook: как подключить Claude Desktop и Cursor (конфигурация, где взять токен, как отозвать).

## Definition of Done

- [ ] Тесты написаны первыми (TDD), включая isolation-тест новой таблицы
- [ ] Commit-гейт зелёный; `db-reviewer` на миграцию, `tenancy-rls-auditor` на таблицу
- [ ] EN + RU для экрана токенов
- [ ] Запись в `docs/brain/`; runbook подключения агента
