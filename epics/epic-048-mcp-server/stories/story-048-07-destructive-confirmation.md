# STORY-048-07 — Подтверждение разрушающих операций в интерфейсе

**Как** пользователь **я хочу**, чтобы необратимое действие агента подтверждалось мной в самом
Bad CRM **чтобы** инструкция, спрятанная в тексте задачи, не могла ни выполнить его, ни изобразить
моё согласие.

## Acceptance (Given/When/Then)

- **Given** инструмент с `destructive: true` **When** агент его вызывает без подтверждения **Then**
  вызов не исполняется: возвращается ссылка на подтверждение в интерфейсе и код `confirmation_required`.
- **Given** запрос подтверждения **When** он создан **Then** он привязан к **хешу аргументов**: агент
  не может подтвердить одно, а исполнить другое.
- **Given** подтверждение **When** пользователь его выдал **Then** оно одноразовое и живёт минуты, а
  не часы; повторное использование отклоняется.
- **Given** подтверждение **When** оно выдано **Then** это произошло в интерфейсе Bad CRM (или по
  ссылке из уведомления, ведущей в интерфейс) — ответ, полученный от самого агента, подтверждением
  не считается ни при какой форме.
- **Given** экран подтверждения **When** он показан **Then** он называет: какой агент, какой
  инструмент, над каким объектом, что именно произойдёт и что это необратимо.
- **Given** каталог первого среза **When** проверяется гейтом **Then** в нём нет ни одного
  `destructive: true`; появление первого такого инструмента требует, чтобы этот механизм уже
  существовал (тест связывает одно с другим).
- **Given** выданное и использованное подтверждение **When** смотрят аудит **Then** видно оба
  события: кто подтвердил и что было исполнено.

## Задачи

- [ ] Тесты первыми: вызов без подтверждения не исполняется; подтверждение с другим хешом аргументов
      не подходит; повторное использование отклоняется; истечение срока.
- [ ] Сущность `McpConfirmation` + миграция с RLS по канону и isolation-тестом.
- [ ] Use-case выдачи и погашения подтверждения; экран в клиенте (EN + RU), уведомление со ссылкой.
- [ ] Поле `destructive` в манифесте + гейт «есть `destructive: true` → механизм подключён».
- [ ] Аудит: выдача подтверждения и его использование.

## Definition of Done
