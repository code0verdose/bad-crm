# STORY-049-06 — Офбординг: отключение, пересылка, экспорт

**Как** администратор **я хочу**, чтобы увольнение закрывало почту и не теряло письма **чтобы**
доступ прекращался сразу, а переписка оставалась у компании.

## Acceptance (Given/When/Then)

- **Given** сотрудник, отключённый в CRM **When** он пытается получить почту **Then** отказ на этой же аутентификации; ящик при этом не удаляется.
- **Given** офбординг **When** админ включает пересылку **Then** входящие на адрес уволенного уходят указанному человеку, и отправитель об этом не уведомляется.
- **Given** офбординг **When** админ запрашивает экспорт **Then** ящик выгружается в переносимом формате (Maildir/JMAP-экспорт), выгрузка доступна по ссылке с коротким TTL и попадает в аудит.
- **Given** удаление ящика **When** оно выполнено **Then** адрес не переиспользуется автоматически: повторная выдача того же адреса — отдельное осознанное действие с предупреждением (письма прошлому владельцу попадут новому).
- **Given** любое из действий **When** оно выполнено **Then** запись в `AuditLog` с повышенной severity (все три права — опасные).

## Задачи

- [ ] Тесты первыми: отключение действует немедленно; пересылка не уведомляет отправителя; повторная выдача адреса требует подтверждения.
- [ ] Расширение офбординга из [EPIC-012](../../epic-012-employee-management/epic.md) почтовой частью.
- [ ] Экспорт ящика через API Stalwart, ссылка с TTL.
